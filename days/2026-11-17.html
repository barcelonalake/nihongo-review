一、定錨最通行的定義・常見誤解・核心詞素

最通行的定義：辭書形＝辞書にある形（字典裡查得到的樣子），也就是動詞「沒有 ます 的原形」。日語動詞的辭書形一定以 う段 結尾（う・く・ぐ・す・つ・ぬ・ぶ・む・る）。

今天的規則（老師的教法）：每個動詞都有組別，先分組再變。

組規則例English／ไทย

常見誤解（今天課堂上真的出現過）：

✗ 趣味は映画を見ます。　→　✓ 趣味は映画を見ることです。
「趣味は〜です」中間要放名詞，ます形是動詞，不能直接放。
✗ 読むます／歌うます／着るます　→　✓ 読む・読みます（二選一）
辭書形和 ます 是兩種形式，不能疊在一起。
✗ 絵を見たことです　→　✓ 絵を見ることです
見たこと 是「看過」（經驗），興趣要用辭書形。
✗ ピカソの絵を好きです　→　✓ ピカソの絵が好きです
✗ 見ます → 見む？　→　✓ 見る（2 組）
見ます・起きます・着ます 的 ます 前雖然是 い段，但屬於 2 組。

核心詞素：

辞書
jisho
字典。「辭書形」就是字典裡的那個樣子。
形
kei / katachi
形式、樣子：ます形、て形、辭書形。
こと（事）
koto
抽象的「事情」，看不見摸不到；具體的東西用 もの。
趣味
shumi
興趣、嗜好。「趣味は＋名詞＋です」。

二、八刀八個方向各切一刀，每刀只留筋骨

1歷史 History

古日語的動詞有兩個形：終止形（句子結束）和連體形（接名詞），例如古語「起く／起くる」 → 大約到室町時代，連體形取代了終止形，兩個合而為一 → 所以今天的辭書形既能結束句子，也能直接接名詞，「見る＋こと」才能這樣直接接上。

見ること | miru koto | 看（這件事）：辭書形直接接名詞 こと | say=みること

2辯證 Dialectics

正：動詞是「在動的事」（見ます）。反：名詞是「靜止的東西」（映画）。合：こと 把動作裝進盒子，讓它變成一個名詞，可以放進「趣味は〜です」、也可以放進「〜ができます」。

趣味は映画です。 | shumi wa eiga desu. | 興趣是電影（名詞直接用）。 | say=しゅみはえいがです。 趣味は映画を見ることです。 | shumi wa eiga o miru koto desu. | 興趣是看電影（動作 → こと）。EN: My hobby is watching movies. TH: งานอดิเรกคือการดูหนัง | say=しゅみはえいがをみることです。

3現象 Phenomenology

回到教室：四個人圍坐，有人說「我喜歡午睡」、有人說「喜歡下棋」。老師一問「趣味は何ですか」，大家下意識回「映画を見ます」，老師就停下來說：這裡要變形。辭書形＋こと 就是從這個卡住的瞬間開始的。

趣味は何ですか。 | shumi wa nan desu ka. | 你的興趣是什麼？ | sp=A 絵を見ることです。 | e o miru koto desu. | 看畫。 | sp=B へえ、そうですか。誰の絵が好きですか。 | hee, sou desu ka. dare no e ga suki desu ka. | 哦，是嗎。你喜歡誰的畫？ | sp=A ピカソの絵が好きです。 | pikaso no e ga suki desu. | 我喜歡畢卡索的畫。 | sp=B

4語言 Linguistics

拆字源：こと＝「事」；有一種說法認為它和「言（こと）」同源，說出來的話＝發生的事（記憶用）。英文對應 -ing／to do（watching movies）；泰語對應 การ＋動詞（การดูหนัง）；粵語像「做嘢」的「嘢」。

語義網（相鄰概念）：

[ ます形 : 有禮貌、句尾 ] | [ もの : 具體的東西 ] -- ( こと ) -- [ 〜のが好き : 口語的名詞化 ] / \ 趣味は V こと です V こと が できます \ / [ 辭書形 : 字典裡的原形 ]

隱喻：こと 是一個盒子，把「看電影」這個動作裝起來，就能拿在手上介紹給別人。

5形式 Formalization

V(ます形) --分組--> V(辭書形) 1G : い段 + ます -> う段 (書きます -> 書く) 2G : 〜 + ます -> 〜る (食べます -> 食べる) 3G : します -> する ; 来ます -> くる 趣味は [ V辭書形 + こと | N ] です [ V辭書形 + こと | N ] が できます

公式在哪裡失效？① 名詞不需要 こと：趣味は旅行です、日本語ができます。② 2 組有 い段 的陷阱：見ます→見る、起きます→起きる（不是 見む）。③ 行きます 是 1 組（行く），来ます 是 3 組（くる，不是 きる）。④ 換成 た形（見たこと）意思就變成「做過」。

EN: Nouns go straight in (趣味は旅行です); only verbs need V-dict + こと. TH: คำนามใช้ได้เลย คำกริยาต้องเติม こと

6存在 Existential

在日本，自我介紹、打工面試、交朋友，都會被問到「趣味は何ですか」「何ができますか」。學會 辭書形＋こと，你就能用一句話說出自己是什麼樣的人、會做什麼。

日本語を話すことができます。 | nihongo o hanasu koto ga dekimasu. | 我會說日語。EN: I can speak Japanese. TH: ฉันพูดภาษาญี่ปุ่นได้ | say=にほんごをはなすことができます。 上手に料理を作ることができません。 | jouzu ni ryouri o tsukuru koto ga dekimasen. | 我不太會做菜。EN: I can't cook well. | say=じょうずにりょうりをつくることができません。

7美感 Aesthetics

想像一本翻開的紙本字典：每個動詞都素著一張臉站在那裡（書く、泳ぐ、登る），沒有 ます 的禮貌外衣。加上 こと，就像替它鑲上一個相框，掛在你的自我介紹牆上。

趣味は山に登ることです。 | shumi wa yama ni noboru koto desu. | 我的興趣是爬山。 | say=しゅみはやまにのぼることです。 趣味はお菓子を作ることです。 | shumi wa okashi o tsukuru koto desu. | 我的興趣是做點心。 | say=しゅみはおかしをつくることです。

8元反思 Meta

我們用什麼隱喻理解它？「原形」：好像 ます形 才是正常，辭書形只是查字典用的。

這個隱喻擋住了什麼？它讓人以為辭書形很少用。其實辭書形就是普通形，朋友之間天天在講（「行く？」「食べる！」），而且以後的 ない形、可能形、〜前に 都從它出發。

換一個隱喻：「素顏」。ます＝出門的妝（禮貌）；辭書形＝素顏（真正的你）；こと＝相框。先認得素顏，才能化各種妝。

三、內觀變成這個概念本身

我是「辭書形」。我住在字典裡，不穿 ます 的外衣，是每個動詞最原本的樣子。

我一定以 う段 結尾：書く、泳ぐ、話す、来る、する。

我的朋友「こと」是一個盒子。我一跳進去，就從「動作」變成「東西」，可以當你的興趣，也可以說明你的能力。

你以後學的 ない形、て形、た形，都要先找到我，所以請先把我記熟。

哪幾刀指向同一個深層結構？歷史、形式、語言三刀都指向同一件事：辭書形本身就能直接修飾名詞（連體形）。「読むこと」和「読む本」（我讀的書）其實是同一個結構，こと 只是一個特別抽象的名詞。

四、壓縮公式・一句話・結構圖

辭書形＋こと = 動作的素顏（ます拿掉，回到 う段） + こと（裝進盒子 = 名詞） -> 趣味は 〜ことです / 〜ことが できます
把 ます 拿掉，變回字典裡的樣子，
再裝進「こと」這個盒子，
動作就變成能介紹自己的「東西」。
EN: Drop masu → dictionary form → add koto = a noun you can use in "my hobby is…" and "I can…".　TH: ตัด ます → รูปพจนานุกรม → เติม こと = คำนาม (การ...)
書きます --(1G: き->く)--> 書く ----+ 食べます --(2G: ます->る)--> 食べる -+--> [ V + こと ] = N します/来ます --(3G)--> する/くる ---+ | +-------+-------+ | | 趣味は N です N が できます (趣味は本を読むことです) (日本語を話すことができます)

記憶法：粵語：こと ≈「嘢」，「睇戲呢樣嘢」＝映画を見ること；普通話：辭書形就是「查字典的那個字」；English: こと ≈ -ing（watching movies）；ไทย：こと ≈ การ（การดูหนัง）。1 組口訣：き→く、み→む、し→す、り→る，往下一格。
