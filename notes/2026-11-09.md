# 2026/11/09（月）課堂整理｜動詞のグループ・て形・〜てください

> 今天辛苦了！一句話重點：先判斷動詞是 **1・2・3 組**，再把ます形變成 **て形**，就可以說 **〜てください**（＝お願いします，禮貌請求）。第 1 組看「ます的前一個音」：いちり→って、にびみ→んで、き→いて、ぎ→いで、し→して；**行きます是特例，て形是 行って**（不是 行いて）。第 2 組把ます改成て（食べます→食べて）；第 3 組：します→して、来ます→来て。還學了 **〜方がわかりません。教えてください**，以及 **どのお皿ですか／そのお皿です、塩はどれですか**。

## 一句話重點
**ます形 → て形 → てください**：分組決定變化；てください 用來拜託別人；〜方＝做法／用法；どの＋名詞、これ・それ・あれ・どれ 用來指東西。

## 1. 動詞のグループ（ます形から）

判斷方法：看 **ます的前一個音**。

| 組別 | 判斷 | 例子 | 羅馬拼音 | 中文 |
|---|---|---|---|---|
| グループ1 | ますの前が **い** | 行きます、買います、読みます、帰ります | ikimasu, kaimasu, yomimasu, kaerimasu | 去、買、讀、回家 |
| グループ2 | ますの前が **え** | 食べます、寝ます | tabemasu, nemasu | 吃、睡 |
| グループ3 | 只有兩個基本動詞 | します、来ます（＋勉強します、コピーします…） | shimasu, kimasu | 做、來 |

**第 2 組特例（い音但卻是第 2 組）**：先記這串  
**あび・い・おき・おり・おち・かり・き・み・でき**

| 日語 | 讀音 | 羅馬拼音 | 中文 |
|---|---|---|---|
| 浴びます | あびます | abimasu | 淋浴 |
| います | います | imasu | 在／有（有生命） |
| 起きます | おきます | okimasu | 起床 |
| 降ります／おります | おります | orimasu | 下降／下（車） |
| 落ちます | おちます | ochimasu | 掉落 |
| 借ります | かります | karimasu | 借入（跟「貸します」相反） |
| 着ます | きます | kimasu | 穿（衣服） |
| 見ます | みます | mimasu | 看 |
| できます | できます | dekimasu | 會／能／完成 |

課堂特別對照：**来ます**（第 3 組，來）和 **着ます**（第 2 組，穿）讀音都是 きます，て形也都是 **きて**，但組別不同。

EN: Group I often has *i* before ます; Group II often has *e*; Group III is only します and 来ます, plus します compounds.  
泰: กลุ่ม 1 ดูเสียงก่อน ます เป็น い; กลุ่ม 2 เป็น え; กลุ่ม 3 คือ します กับ 来ます。

## 2. て形の作り方

### グループ3
します → **して**／来ます → **来て**（きて）  
勉強します → 勉強して、コピーします → コピーして。

### グループ2
把 ます 改成 て：食べます→食べて、起きます→起きて、入れます→入れて、教えます→教えて。

### グループ1（看ます的前一個音）
| ますの前 | て形 | 例子 |
|---|---|---|
| い・ち・り | って | 使います→使って、持ちます→持って、帰ります→帰って、切ります→切って、買います→買って |
| に・び・み | んで | 死にます→死んで、遊びます→遊んで、飲みます→飲んで、読みます→読んで |
| き | いて | 書きます→書いて、置きます→置いて **（例外：行きます→行って）** |
| ぎ | いで | 泳ぎます→泳いで |
| し | して | 話します→話して、出します→出して、貸します→貸して |

**スペシャル：行きます → 行って**（不是 行きて／行いて）。老師反覆提醒。

複合：持っていきます → **持っていって**。

EN: Look at the sound before ます, then apply the chart; ikimasu is irregular (itte, not iite).  
泰: ดูเสียงหน้า ます แล้วเปลี่ยน；行きます เป็นรูปพิเศษ 行って。

## 3. 〜てください（依頼）

**てください ＝ お願いします**（禮貌拜託）。只說 **て** 比較隨便（カジュアル）。前面常加 **すみません、／すみませんが、**。

| 日語 | 羅馬拼音 | 中文 |
|---|---|---|
| サラダを作ってください。 | sarada o tsukutte kudasai. | 請做沙拉。 |
| お皿を洗ってください。 | osara o aratte kudasai. | 請洗碗盤。 |
| 手伝ってください。 | tetsudatte kudasai. | 請幫我一下。 |
| 写真を撮ってください。 | shashin o totte kudasai. | 請拍照。 |
| 塩を取ってください。 | shio o totte kudasai. | 請把鹽拿過來。 |
| CDを貸してください。 | shi-di- o kashite kudasai. | 請把 CD 借我。 |
| 冷蔵庫から飲み物を出してください。 | reizouko kara nomimono o dashite kudasai. | 請從冰箱把飲料拿出來。 |
| 冷蔵庫にケーキを入れてください。 | reizouko ni ke-ki o irete kudasai. | 請把蛋糕放進冰箱。 |
| テーブルにお皿を置いてください。 | te-buru ni osara o oite kudasai. | 請把盤子放到桌上。 |
| このパンをナイフで切ってください。 | kono pan o naifu de kitte kudasai. | 請用這把刀子切這個麵包。 |
| 野菜を洗ってください。 | yasai o aratte kudasai. | 請洗蔬菜。 |
| ちょっと待ってください。 | chotto matte kudasai. | 請稍等。 |
| 頑張ってください。 | ganbatte kudasai. | 請加油。 |

**取って／置いて／持っていって** 不一樣：取って＝拿過來遞給我；置いて＝放到某處放著；持っていって＝搬／拿過去。

## 4. 助詞：に・で・から

- **に**：放置／進去的目的地。テーブル**に**置いてください。冷蔵庫**に**入れてください。
- **で**：工具或手段。ナイフ**で**切ります。箸**で**食べます。ペン**で**書きます。電話／スマホ**で**注文します。自転車**で**行きます。
- **から**：從哪裡拿出來。冷蔵庫**から**出してください。
- **を**：動作對象。料理**を**テーブルに置いてください（不是 料理で）。
- **歩いて** 是て形當「方式」，不是「道具で」。

## 5. 〜方（做法、用法）

ます形去掉ます，加 **方（かた）**。

| ます形 | 〜方 | 羅馬拼音 | 中文 |
|---|---|---|---|
| 作ります | 作り方 | tsukurikata | 做法 |
| 使います | 使い方 | tsukaikata | 用法 |
| 切ります | 切り方 | kirikata | 切法 |
| 読みます | 読み方 | yomikata | 讀法 |
| 書きます | 書き方 | kakikata | 寫法 |
| 買います | 買い方 | kaikata | 買法 |
| 食べます | 食べ方 | tabekata | 吃法 |

對話：

- A：カレーの作り方がわかりません。すみませんが、作り方を教えてください。
- 會的人：いいですよ。教えます。
- 不會的人：すみません、私もわかりませんから、（Cさんに）聞いてください。

## 6. どの・これそれあれ

- **どの＋名詞**：哪一個～？ どのお皿ですか。どのスプーンですか。
- 回答用 **この／その／あの＋名詞**。そのお皿です。
- 不加名詞時用 **どれ／これ／それ／あれ**。塩はどれですか。— それです。
- 課堂還練了：砂糖はどれですか、醤油はどれですか、お茶はどれですか。

## 7. 課堂上聽到的錯誤（✗→✓）
- ✗ 行きて／行いて → ✓ **行って**
- ✗ 泳って → ✓ **泳いで**
- ✗ 手伝いて → ✓ **手伝って**
- ✗ 作りてください → ✓ **作ってください**
- ✗ 料理でテーブルに置いてください → ✓ **料理を**テーブルに置いてください
- 取って・置いて・持っていって 用錯情境
- 問「哪一個」時用 この～ですか，應先問 **どの～ですか**
