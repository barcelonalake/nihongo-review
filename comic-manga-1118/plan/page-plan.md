# Page Plan — 聴解・漢字・〜ができます／ことができます 漫畫版（12 pages）
Skill: baoyu-comic --art manga --tone warm
Date: 2026-11-18 | 4～8課 総合確認テスト（聴解題型）、漢字 休・名・昼・間、第9課 N＋ができます、辞書形＋ことができます

P01 聴解テスト：まず質問を聞いて、話を聞いて、いちばんいいものを1つ選びます。
P02 どこにいますか：バス停の前にいます／前にポストがあります／その前に神社があります。
P03 どうして〜から：どうして買いませんでしたか → いいパソコンがありませんでしたから。
P04 何と言いますか：映画を見に行きませんか／あ、乗ります！／手伝ってください。
P05 もらいました：そのネクタイ、いいですね → 父にもらいました（に）。
P06 漢字 休（人＋木）・名（夕＋口）。
P07 漢字 昼・間：昼休み、門の間に日、机の間に10円、期末試験は名前を忘れないで。
P08 新しい言葉：クラブに入ります、試験に申し込みます、飲み会に参加します、自転車に乗ります。
P09 〜ができます：いろいろなイベント、スキー旅行に参加したい、スキーができますか、すごいですね。
P10 辞書形＋ことができます：漢字を書くことができません → 書道教室へ習いに行きます。
P11 あまり〜できません：辛い料理、自転車に乗ることができませんから歩いて学校へ。
P12 まとめ：二つの形、明日は作文「私の趣味」、何を書くか考えておきます。
